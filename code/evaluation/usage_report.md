# Token Usage and Cost Report — Buy or Wait?

## Summary

This solution was built using two AI providers across two distinct phases:
development (code generation) and one-off data resolution (image extraction).

## 1. Development Phase — Codex (GPT-based, via VS Code extension)

- **Provider**: OpenAI Codex (VS Code integration)
- **Purpose**: Generated data_loader.py, currency.py, forecast.py,
  decision_engine.py, formatter.py, and evaluation/evaluate.py
- **Usage**: Subscription/quota-based access (not billed per-token via API;
  usage counted against Codex's built-in session quota, which was exhausted
  partway through development)
- **Note**: Exact token counts are not exposed by the Codex VS Code extension
  UI. Development spanned approximately 8-10 conversational turns generating
  and iterating on ~700 lines of Python across 6 files.

## 2. Data Resolution Phase — Groq API (qwen/qwen3.6-27b)

- **Provider**: Groq
- **Model**: qwen/qwen3.6-27b (vision-capable)
- **Purpose**: Extracted two missing transaction amounts from linked images
  (event_1442 — rent receipt, event_1786 — invoice) that could not be treated
  as zero per the problem statement's instructions.
- **Model calls**: 2 (one per image)
- **Estimated tokens per call**: ~1,500 input tokens (image + prompt),
  ~150-300 output tokens (including model reasoning trace before the final
  numeric answer)
- **Total estimated tokens**: ~3,600 (≈3,000 input + ~600 output)
- **Groq qwen/qwen3.6-27b pricing** (approximate, per Groq's public pricing):
  ~$0.20 per million input tokens, ~$0.20 per million output tokens
- **Estimated cost for this run**: less than $0.01 (well under one cent)

## 3. Full-Dataset Run (producing output.csv)

The final `output.csv` covering all 250 requests was generated by
**deterministic Python code** (data_loader → currency → forecast →
decision_engine → formatter) with **no per-request LLM calls** — the two
Groq calls above were one-off, applied once to patch missing source data,
not run per-request. This keeps the production pipeline fast, reproducible,
and effectively free to re-run at scale.
